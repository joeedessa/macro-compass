Sessions

Which cash equity sessions are trading right now. Everything below is the current session where a market is open, and the last completed session where it is not — each card says which.

Around the world

Every region's own indices, quoted in their own currency and measured against their own exchange's previous close — so Asia reads as Asia saw it. Blocks run in session order, which is the order the day actually happens in.

Cross-asset

The instruments that set the tone across asset classes, with today's path drawn from five-minute bars against the previous close. Flat lines mean the market has not opened yet.

Read of the session

Movers

Ranked by size of move against each instrument's own 60-day volatility, so a 2% day in something that never moves outranks a 4% day in something that always does. The σ figure is that ratio.

Breadth

Share of each block trading higher on the session — where participation is broad and where it is a handful of names.

On the calendar

Watchlist names with something scheduled today or tomorrow, from the TradingView events feed.
